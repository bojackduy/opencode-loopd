Good questions.

What is opencode-loopd?

An OpenCode plugin that supervises background goals. OpenCode runs worker sessions; loopd manages goals, checks, budgets, schedules, coordination, and the dashboard.

Do I need to know how to code?

You can create a goal in plain language. OpenCode still needs to be installed and configured with a model and agent.

How do workers avoid editing the same file?

Workers claim exact file paths before editing. Disjoint claims can run concurrently; conflicts return owner and path details. Read-only goals do not reserve source files.

Can I manage goals in other projects?

Yes. Register target directories, create goals with a directory, then inspect and steer across projects from one manager session.

How do I install it?

Add @bojackduy/opencode-loopd to the OpenCode server and TUI plugin settings, restart OpenCode, then run /goal or open /loop.
